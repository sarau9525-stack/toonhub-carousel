# تون‌هاب | TOONHUB 3D Carousel

ویترین تعاملی تمام‌صفحه فیگورهای سه‌بعدی ساخته‌شده با React + TypeScript + Vite + Tailwind CSS.

## 🚀 ویژگی‌ها
- ۴ کاراکتر سه‌بعدی جذاب با انیمیشن‌های ترنزیشن روان و پالت رنگی داینامیک
- فریمورک مدرن React 19 + Vite + Tailwind CSS
- پشتیبانی کامل از زبان فارسی و انگلیسی (دوزبانه)
- استقرار خودکار روی Cloudflare Pages با GitHub Actions

## 🛠️ دستورات
```bash
npm install
npm run dev
npm run build
```
